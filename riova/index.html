Riova


Riova is an open source game engine that is currently under active development. The engine's end goal is to be the powerhouse of Piceno's indie titles. Given its open source nature, anyone can view and download its source code on Github: Riova. Riova's current primary graphics API is OpenGL, however the addition of Vulkan and DirectX options are anticipated. Riova's sound API has yet to be chosen. Physics for 3D objects is currently yet to be implemented. This project strives for efficient progress.
