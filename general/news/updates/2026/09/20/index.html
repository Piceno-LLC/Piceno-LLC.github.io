Making Progress: Neon Vista Updates

Author: Mario Aguilera Piceno

Date: 09/20/2026

Neon vista is a mystery game that empowers players to solve challenging yet fun objectives to unlock and progress through an endearing journey. Neon Vista is currently in active development. All progress is being done on the Unity Engine.

There has been heavy ongoing features being added and the core mechanics are still being worked. Altough a firm release date is still far from available, progression is being done actively.
